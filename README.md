# Titanic Dataset — Exploratory Data Analysis (EDA)

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic passenger dataset using Python. The objective is to understand the dataset, explore missing values, analyze statistical distributions, identify relationships between variables, and discover patterns associated with passenger survival.

The analysis was developed in **Google Colab** using Python data analysis and visualization libraries.

## Objectives

* Understand the structure and characteristics of the dataset.
* Perform statistical analysis using Pandas.
* Identify missing values and duplicate records.
* Explore passenger age and fare distributions.
* Analyze survival patterns across passenger groups.
* Visualize relationships using multiple statistical plots.
* Summarize findings in a PDF report.

## Technologies Used

* **Python** — data analysis and programming
* **Pandas** — data manipulation and statistical summaries
* **NumPy** — numerical operations
* **Matplotlib** — data visualization
* **Seaborn** — statistical visualization
* **Google Colab** — cloud-based notebook environment

## Dataset

The Titanic dataset contains information about passengers, including survival status, passenger class, sex, age, fare, and other travel-related attributes.

The dataset is loaded using Seaborn's built-in Titanic dataset function. An alternative CSV source is provided in the notebook if the built-in dataset cannot be loaded.

## Analysis Performed

### 1. Data Inspection

* Displayed the first five rows.
* Examined dataset dimensions and column names.
* Inspected data types and statistical summaries.

### 2. Data Quality Analysis

* Counted missing values in each column.
* Calculated missing-value percentages.
* Checked for duplicate rows.
* Examined categorical values using `value_counts()`.

### 3. Data Visualization

* Histograms to explore age and fare distributions.
* Boxplots to compare age by survival status and fares by passenger class.
* Scatterplot to examine age, fare, and survival.
* Countplot to compare survival counts.
* Pairplot to explore relationships among selected variables.
* Correlation heatmap to examine linear relationships between numeric variables.

### 4. Survival Analysis

* Calculated the overall survival rate.
* Compared survival rates by sex.
* Compared survival rates by passenger class.
* Explored survival rates across age groups.

## Key Findings

The analysis is designed to investigate the following questions:

* Which age ranges are represented most frequently?
* How are passenger fares distributed?
* How does survival vary by sex and passenger class?
* Are there unusual fare values or other potential outliers?
* Which numeric variables show stronger or weaker correlations?

The final findings should be interpreted from the actual tables and plots generated by the notebook. Correlation and group differences do not, by themselves, establish causation.
